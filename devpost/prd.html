FlowMine — Product Requirements

Find and collapse repetitive activity logs into interactive automation flowcharts.

The Core Journey

graph TD A[Arrival: Monthly Log Loaded] --> B[Toggle: Switch to Support Tickets] B --> C[Action: Find the Loop] C --> D{Animation: 2.5s Collapse} D --> E[Land: ×4 Badge & Script Reveal] E --> F[Action: Run Simulation] F --> G[Progress: Pulsing & Ticking] G --> H[Success: Green State & Done]

Key Behaviors & Success Criteria

1. The Collapse Animation

Visualizes the transformation from "mess" to "order."

  • Highlight repeating lines in violet (0.4s).
  • Stack repeat groups vertically (0.6s).
  • Fold stack into a flowchart node (0.6s).
  • Pop "×4" badge with a bounce (0.3s).
  • Total sequence matches 2.5s timing.

2. Interactive Run Simulation

Proves the automation works through visual feedback.

  • Active step glows violet with thick outline.
  • Badge ticks progress (e.g., 1/4, 2/4) during loops.
  • Completed steps turn green.
  • Output panel prints actions (e.g., "-> open report_feb.xlsx").

3. Look & Feel

  • Navy/Violet palette for primary UI/State.
  • Amber for variable data; Green for success.
  • Monospace for log lines and script.
  • Light-grey grid background.

Product Decisions

Warm Start

Pre-loading the "Monthly report" log ensures the first interaction is meaningful and demo-ready.

Fade-in Script

The script appears instantly after animation to keep the eye moving toward the "Run" action without typing delays.

Intentional Timing

2.5s for the animation is the "Goldilocks" zone—satisfyingly detailed but fast enough for a 60-second demo.

States & Edge Cases

Empty Log: "The log is empty. Paste one action per line..."
No Loop Found: "No repeated sequence found. FlowMine needs a group..."
