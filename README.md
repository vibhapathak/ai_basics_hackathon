# FlowMine

Paste a log of repetitive work. FlowMine finds the loop hiding in it, draws it as a flowchart, and writes the script that automates it.

**Who it's for:** people who repeat the same chores without noticing, such as support agents working tickets or ops staff compiling monthly reports.

## Run it
Open `index.html` in a browser. No install and no build step.

## How it was built
Started from an empty folder on Oct 21, 2026 for the Devpost "Build with AI Basics" hackathon, using the Devpost Learn skills. The planning docs are in `devpost/`: `scope.md`, `prd.md`, `spec.md`. Vanilla HTML, CSS and JavaScript.
